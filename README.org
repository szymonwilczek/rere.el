Passive, read-only code review interface for interactive Git rebase
sessions in GNU Emacs.

Provides a Magit-powered virtual staging area to inspect, verify, and accept
changes line-by-line without touching the Git index or working tree.

** Why?

For years, my personal review workflow during an interactive Git rebase
relied on a habit I coined /unpacking a commit/. Whenever I paused at a commit
marked with =edit=, I would unpack it, typically [[https://github.com/szymonwilczek/dotfiles/blob/main/emacs/.config/emacs/modules/git/git-mod.el#L25][like this]], and step through
the diff hunk by hunk using Magit's (or at the previous time - [[https://github.com/szymonwilczek/dotfiles/blob/main/emacs/.config/emacs/modules/git/git-mod.el#L4][Lazygit]]) staging
area, verifying every change before committing it back.

This technique gave me complete confidence in what went into each commit,
but it was slow, tedious, and stressful. Touching the working tree and dirtying
the index constantly posed risks: accidental edits, dirty working state, lost
work-in-progress, and unnecessary commit SHA churn when nothing changed.

For my own peace of mind, I wanted an automated solution that preserved the
tactile satisfaction of staging changes without ever touching the Git tree
or index. /"Unpacking a commit"/ was my own workflow invention - and =rere.el=
is its direct evolution: a passive, virtual staging area that lets you
review diffs with Magit ergonomics while leaving your repository state
completely untouched. There are certainly other tools and other approaches,
but =rere= was built to fit my workflow. It was designed by me, for me - and
shared in case it scratches the same itch for *you*. If this sounds like how
you review code as well, go ahead - that's why this package is public.

** What's Inside

- *Virtual Staging Area:* Review diffs line-by-line, hunk-by-hunk, or
  file-by-file in memory without touching the index or working copy.
- *Persistent Review State:* Remembers reviewed and flagged lines across
  buffer reloads and rebase sessions via content-addressed hashing.  A
  line is identified by its file, content and occurrence, so edits
  elsewhere in the file do not reset it.
- *Magit-Style Partial Review:* Like Magit's staged and unstaged diffs,
  pending changes are shown on top of the already reviewed ones: reviewed
  lines stay visible as context around what is left to review, trimmed to
  a few lines around each change like =git diff=.
- *Line Numbers:* Old and new file line numbers next to every diff line.
- *Diffstat Overview:* Per-file summary of additions, removals, and review
  progress displayed at the top of the buffer.
- *Word-Level Refinement:* Highlights word-level differences within
  modified lines for precise change identification.
- *Stinky Changes:* Flag suspicious lines for later review.  Flagged lines
  are collected in a dedicated /Stinky changes/ section and block 100%
  completion until resolved.  Accepting a flagged line clears its flag.
- *Focus Mode:* Narrow the view to a single file to reduce noise during
  review.
- *Smart Accept and Undo:* Context-aware operations that act on the element
  under the cursor (line, hunk, file) or a visual region.
- *Incremental Updates:* Accepting, undoing and flagging only re-render the
  touched files, so the buffer stays responsive and in sync on diffs with
  tens of thousands of changed lines.
- *No Git side effects:* Passive - no =git add=, =git commit=, etc; commit SHAs
  remain intact.
- *Magit-Native UI:* Built on =magit-section= with familiar faces, folding,
  Evil navigation, and jump to source.

** Installation

*** Requirements
- GNU Emacs 28.1 or newer.
- [[https://magit.vc][Magit]] 3.0 or newer.

*** use-package with built-in :vc
#+begin_src elisp
  (use-package rere
    :vc (:url "https://github.com/szymonwilczek/rere.el" :branch "main")
    :commands (rere))
#+end_src

*** straight.el
#+begin_src elisp
  (use-package rere
    :straight (rere :type git :host github :repo "szymonwilczek/rere.el")
    :commands (rere))
#+end_src

*** Elpaca
#+begin_src elisp
  (use-package rere
    :ensure (:host github :repo "szymonwilczek/rere.el")
    :commands (rere))
#+end_src

*** Manual / Git Clone
#+begin_src bash
  git clone https://github.com/szymonwilczek/rere.el.git \
      ~/.config/emacs/packages/rere.el
#+end_src

#+begin_src elisp
  (use-package rere
    :load-path "~/.config/emacs/packages/rere.el"
    :commands (rere))
#+end_src

** Key Bindings

*** Review

| Key   | Command           | Action                                          |
|-------+-------------------+-------------------------------------------------|
| =s= / =S= | ~rere-smart-accept~ | Smart accept: line, hunk, file, or category     |
|       |                   | in Pending or Stinky changes                    |
| =u=     | ~rere-unaccept~     | Smart undo: line, hunk, or file back to Pending |
| =m=     | ~rere-toggle-flag~  | Toggle flag (stinky) on line or region          |
| =M=     | ~rere-next-flagged~ | Jump to next flagged line                       |

*** Navigation

| Key   | Command                | Action                               |
|-------+------------------------+--------------------------------------|
| =n= / =p= | ~rere-next-diff-line~    | Jump to next / previous diff line    |
| =]= / =[= | ~rere-next-file~         | Jump to next / previous file         |
| =}= / ={= | ~rere-next-pending-file~ | Jump to next / previous pending file |
| =RET=   | ~rere-open-file~         | Open source file at diff line        |

*** Display

| Key | Command             | Action                                 |
|-----+---------------------+----------------------------------------|
| =TAB= | ~rere-toggle-section~ | Toggle section visibility              |
| =f=   | ~rere-toggle-focus~   | Toggle focus mode on file at point     |
| =c=   | ~rere-toggle-context~ | Toggle context lines in diff hunks     |
| =r=   | ~rere-refresh~        | Re-parse diff, preserve reviewed state |
| =q=   | ~rere-quit~           | Restore window layout and quit         |

All bindings work in both Emacs and Evil (normal, motion, and visual states).
Visual selections are supported for =s=, =u=, and =m=.

** Options

| Variable               | Default | Description                                 |
|------------------------+---------+---------------------------------------------|
| ~rere-buffer-name~       | ~"*rere*"~  | Buffer name used for the review buffer.     |
| ~rere-refine-highlight~  | ~t~       | Enable word-level difference highlighting.  |
| ~rere-show-diffstat~     | ~t~       | Display per-file diffstat summary section.  |
| ~rere-show-line-numbers~ | ~t~       | Show file line numbers next to diff lines.  |
| ~rere-context-lines~     | ~3~       | Context lines around changes (like =git -U=). |

** Faces

| Face                 | Description                           |
|----------------------+---------------------------------------|
| ~rere-flagged-line~    | Face for flagged (stinky) diff lines. |
| ~rere-flagged-heading~ | Face for the Stinky changes heading.  |
| ~rere-current-line~    | Face highlighting the line at point.  |
| ~rere-line-number~     | Face for file line numbers.           |
